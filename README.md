# url.cecil.app

_Cecil/URL_ website.

## Development

### Install

```bash
composer install
curl -LO https://cecil.app/cecil.phar
```

> Requires Cecil 9.29+ and the PHP GD extension with FreeType support (Open Graph images generated by the [ogimage](https://github.com/Cecilapp/theme-ogimage) theme).

### Build

```bash
php cecil.phar serve -v
```
